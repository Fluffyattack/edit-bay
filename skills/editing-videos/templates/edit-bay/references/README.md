# References

One folder per reference: `references/<short-name>/note.md` (template: `_reference-note-template.md`),
plus an optional 720p copy, screenshots and a contact sheet.

- Collect references any time, not just while a project is running.
- Write down *what* you like at the moment you save it — later you won't remember.
- Mix single elements from several references (captions from one, pacing from another) rather than
  rebuilding one creator's style.
- Local copies of other people's videos are for private analysis only; their footage, music and graphics
  never go into our videos.
