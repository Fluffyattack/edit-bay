# Projects

One folder per video: `YYYY-MM-DD-short-title/`, created with `new_project.py`.

- `brief.md` – message, audience, platform, length, references, script or not, sign-offs
- `footage/` – recordings (or note in `brief.md` where large files live)
- `work/` – transcripts, cut list, words file, captions, overlays plan
- `graphics/` – overlay PNGs and the code that generates them
- `previews/` – rough cuts, stills, test clips, previews — always with a version number
- `final/` – the delivered video
- `storyboard.md`, `notes.md`
