# Learnings

Newest first. Each entry is a rule for **all** future videos. One-off fixes belong in the
project's `notes.md`, not here.

```
## YYYY-MM-DD – Short rule title
- Rule: what to do from now on (concrete and checkable: numbers, positions, durations)
- Why: the reason, so edge cases are judged sensibly instead of followed blindly
- Origin: project and timecode where it came up
- Playbook: file and section once it has been folded in
```
