# Edit bay

Every video (shorts, vlogs, long-form) is made in this folder, each one in a fresh chat.
What one project teaches is written down here, so the next project starts ahead.

## Layout

| Path | Purpose |
|---|---|
| `inbox/` | Anything not filed yet: voice memos, ideas, notes, raw files |
| `references/` | Reference notes: videos and images you like, and *what exactly* you like about them |
| `playbooks/` | Proven style rules: `general.md` plus one file per format (e.g. `talking-head-short.md`, `vlog.md`) |
| `library/` | Reusable parts: sounds, music, fonts, graphic generators, caption styles |
| `projects/` | One folder per video: brief, working files, previews, notes |
| `LEARNINGS.md` | Log of rules learned from notes, with date, reason and origin |

## How we work

1. **Before cutting**, read `LEARNINGS.md`, the matching playbook and the reference notes named in the brief.
2. Stages: **brief → footage review → rough cut → design pass ⇄ preview → finish.**
   Two sign-offs: *story lock* after the rough cut, *picture lock* after the preview. Going back is always allowed.
3. **Iterate on cheap formats first**: storyboard text, then stills, then test clips, then a 720p preview.
   Full resolution only after picture lock.
4. Notes are logged as **version + timecode — what I see — what I want**.
5. Notes about one video stay in that project's `notes.md`. Notes that should hold for every video become an
   entry in `LEARNINGS.md` and, once proven, part of a playbook.
6. **At the end of every project**, confirm that all learnings from the chat are saved.
