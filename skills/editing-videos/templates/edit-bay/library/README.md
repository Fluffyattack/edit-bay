# Library

Reusable parts for many videos:

- `sounds/` – sound effects (licensed or self-made only; note source and licence in `sounds/LICENSES.md`)
- `music/` – background music (same rule)
- `fonts/` – .ttf/.otf files, passed to `render.py --fonts-dir`
- `graphics/` – scripts that generate recurring overlays (lower third, quote card, price tag …)
- `caption-styles.md` – `make_captions.py` settings that worked

Create subfolders as needed.
